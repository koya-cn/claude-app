# 🔍 claude-resume

Claude CLI の過去のセッション履歴（`~/.claude/`）から、キーワードでプロンプトやAIの回答を検索し、当時の作業ディレクトリに移動してセッションを再開（resume）するためのツールです。

## ✨ 特徴

* **ユーザー＆AI 双方の出力を検索**: 自分が打ったプロンプト（🙋）だけでなく、AIの返答（🤖）も検索対象です。
* **ピンポイント抽出**: ヒットした「その行」だけを表示するため、会話が長くてもノイズがありません。
* **プロジェクト単位のグループ化**: `cwd`（実行ディレクトリ）ごとに結果をまとめるので、文脈が追いやすいです。
* **自動コマンド生成**: `cd <path> && claude --resume <id>` を出力。コピペで即復帰。
* **直近セッション一覧**: `--recent` で「最近何をしていたか」を時系列で確認。
* **Claude による要約**: `--summary` で直近の作業内容を Claude が自動要約。
* **未完了検出**: `--todo` で「やり残し」の疑いがあるセッションを全プロジェクト横断で検出。`--ai` を併用すると Claude がノイズを除外し A:中断/B:最終工程残り/C:未着手 に分類。
* **ブラウザUI**: `--web` でローカルブラウザから見やすいインターフェースで履歴を閲覧・検索。「⚠ 未完了を調べる」ボタンから専用ページで検出・トリアージも可能。

## 🚀 インストール方法

1. スクリプトの内容を `claude-resume.py` として保存します。
2. パスの通ったディレクトリ（例: `/usr/local/bin`）へインストールします。

   **コピーする場合:**
   ```bash
   sudo cp claude-resume.py /usr/local/bin/claude-resume
   sudo chmod +x /usr/local/bin/claude-resume
   ```

   **シンボリックリンクを使う場合（スクリプト更新時に再コピー不要）:**
   ```bash
   sudo ln -s /path/to/claude-resume.py /usr/local/bin/claude-resume
   chmod +x /path/to/claude-resume.py
   ```

## 💻 使い方

```bash
claude-resume <検索キーワード>    # キーワード検索
claude-resume -r [N]             # 直近 N セッションの一覧（デフォルト: 5）
claude-resume --recent [N]       # 同上
claude-resume -s [N]             # 直近 N セッションを一覧 + Claude 要約（デフォルト: 5）
claude-resume --summary [N]      # 同上
claude-resume -t [N]             # 未完了の疑いがあるセッションを検出（最大 N 件走査、デフォルト: 200）
claude-resume --todo [N]         # 同上
claude-resume --todo --strict    # 明確なシグナルのある候補（strong）のみ表示
claude-resume --todo --ai        # 検出結果を Claude が A/B/C に分類・トリアージ
claude-resume -w [PORT]          # ブラウザUIを起動（デフォルトポート: 8080）
claude-resume --web [PORT]       # 同上
```

### 未完了検出 (`-t` / `--todo`)

過去の Claude セッションを全プロジェクト横断で走査し、「やり残し」の疑いがある作業を検出します。

判定はヒューリスティック（軽量・LLM不使用）で、候補を **2層**に分けます。

**strong（明確なシグナルあり）** — 以下のいずれかにヒット:

| シグナル | 説明 | 強度 |
|----------|------|------|
| AI未応答で終了 | 末尾がユーザー発言のまま（応答前に中断） | +3 |
| やり残し表現 | 末尾AI発話に「あとで/残り/未実装/対応待ち/次のステップ」等 | +2 |
| 未対応のチェックリスト | 末尾AI発話に未チェックの `- [ ]` が残る | +2 |
| 確認/承認待ち | 末尾AI発話が質問・確認で終了 | +1 |

**weak（完了報告のない作業）** — 上記シグナルは無いが、末尾AIに完了報告（「完了しました / マージしました / コミットしました / PRを作成しました / ✅」等）も無く、言い切れていないもの。既定では表示するが、`--strict` で除外できる。

- スキル実行ログ（`/instinct-status` 等）やコマンド注入メッセージ・`<task-notification>` 等のメタは自動除外
- 各シグナルは**一致した実際の行（根拠）**も併せて表示
- `--strict`: weak を除外し、明確なシグナルのある候補（strong）のみ表示

**ノイズ除外（完了とみなす）条件** — 精度を高めるため、以下は「やり残し」ではなく完了として除外します:

- **作業完了の報告**（完了句は末尾付近に限らず発話全体を走査。「完了です。- 〜」のように冒頭報告でも拾う）
- **AIの回答に納得して自然終了**: 締めの確認/提案質問（`解決しましたか?` / `何をしますか?` / `お手伝いしましょうか?`）で終わるもの
- **番号付きメニューで次の指示待ち**（提示された選択肢内の「続き」等のやり残し語も拾わない）
- **ねぎらい/追加提案で締め**（`必要ならお知らせください` 等）
- **ユーザー主導の中断**（末尾が `[Request interrupted by user]`）= 納得して停止とみなす
- **残作業なしの明言**（`特に作業はありません` 等）

> **完了の扱い**: commit / PR作成 / マージ / デプロイは「完了」とみなします。ただし「PR作成。次は△△」のように **未実装・チェックリスト残り等の strong シグナルを伴う場合は候補に残ります**。

```text
⚠️  未完了の疑いがあるセッション (48件)
============================================================
── 未完了のシグナルあり (35件) ──
 [ 1] 06/08 19:43 | gas-scripts  (強度 5)
      💬 Meet議事録 → Asana自動登録フローを作りたい
      ⚠ AI未応答で終了
      ⚠ やり残し表現: お願いします
         └ 一致した行: プランをまとめました。レビューをお願いします。
      🚀 cd /home/user/gas-scripts && claude --resume a61c4782-...
      ------------------------------------------------------

── 完了報告のない作業（弱い候補・要確認 13件） ──
 [36] ...
```

`--ai` を併用すると、検出結果を Claude (Haiku) がノイズ除外したうえで分類します。

```bash
claude-resume --todo --ai
```

```text
🤖 トリアージ結果（A: 中断/保留, B: 最終工程残り, C: 未着手）:
============================================================
[A] gas-scripts: Meet議事録→Asana自動登録フロー（計画完成、レビュー待ち）
[B] aide-integrity-check: PR#24 のタイトル確認・マージ待ち
[C] gas-scripts: RSA認証下のRSSをGmailへ送信（要件確認中）
```

> 検出対象は各自ローカルの `~/.claude` セッションです。`dirs` 設定（後述）に従って走査範囲が決まります。

### ブラウザUI (`-w` / `--web`)

```bash
claude-resume -w
# または
claude-resume --web 3000  # ポート指定
```

ブラウザで `http://localhost:8080` が自動的に開き、以下の機能が利用できます：

- **直近セッション一覧**: カード形式で見やすく表示
- **ターン単位の会話表示**: User/AI のやり取りを折りたたみ表示
- **キーワード検索**: リアルタイムで検索結果を表示
- **コマンドコピー**: ワンクリックで `claude --resume` コマンドをコピー
- **未完了を調べる**: ヘッダーの「⚠ 未完了を調べる」ボタンで専用ページに切替。開くと全セッションを走査し、strong 候補を一覧表示（各候補に一致した根拠の行を表示）、weak 候補（完了報告のない作業）は折りたたみで表示。「AI でトリアージ」で A/B/C に分類した要約を生成。要約結果は localStorage に保存され、候補集合が変化するまで再訪時に即表示される。
- **「✓ 完了にする」**: 各未完候補カードの「✓ 完了にする」ボタンで、そのセッションを完了扱いにして一覧から除外できる。状態は `~/.claude-resume-done.json` にサーバー側保存され、ブラウザ／端末をまたいで維持される（CLI の `--todo` にも反映）。完了にした後でそのセッションを再度進めて未完になった場合は、自動的に再表示される。
- **セッション詳細の全文表示**: 詳細ポップアップは AI のテキストだけでなく、**シェルコマンド等のツール実行（⚙）とその実行結果（↳）**、および AI の思考プロセス（💭・折りたたみ）も時系列で表示する。長い実行結果はスクロール表示。

**特徴:**
- 外部依存ゼロ（Python 標準ライブラリのみ）
- レスポンシブデザイン
- ローカル実行のみ（プライバシー保護）
- **AI 要約**: セッション詳細を開いて「AI 要約を生成」ボタンを押すと、Claude Haiku が先頭 3 ターン＋直近 5 ターンを元に内容を箇条書きで要約。要約結果はブラウザの localStorage に自動保存され、次回同じセッションを開いた際は即座に表示される。セッションのメッセージ数が変化した場合はキャッシュを自動破棄して再生成可能。

## ⚙️ 設定ファイル (`~/.claude-resume.json`)

ホームディレクトリに `~/.claude-resume.json` を作成することで動作をカスタマイズできます。

### 設定項目

| キー | 型 | デフォルト | 説明 |
|------|----|-----------|------|
| `dirs` | 文字列の配列 | `["~/.claude"]` | 全操作の対象ディレクトリ（キーワード検索・直近一覧・要約） |

### 設定例

```json
{
  "dirs": [
    "~/.claude",
    "/path/to/another/claude-sessions"
  ]
}
```

`dirs` を省略した場合や設定ファイルが存在しない場合は、デフォルトの `~/.claude` のみが対象となります。

### 完了状態ファイル (`~/.claude-resume-done.json`)

Web UI の「✓ 完了にする」で完了扱いにしたセッションが記録されるファイルです（自動生成・自動更新）。`session_id` と完了操作時点の最終更新時刻を保持し、未完了検出（Web UI・CLI `--todo`）から除外する判定に使われます。手動編集は不要です。

```json
{
  "done": {
    "<session_id>": 1781493134498
  }
}
```

> **補足**: `dirs` に `sessions/*.json` しかないディレクトリ（Windows の Claude Desktop など）を指定した場合、`--recent` / `--summary` ではアクティブセッションのみが表示されます（`history.jsonl` がないためプロンプト文字列は表示されません）。

## 🛠 カスタマイズ

スクリプト内の以下の箇所を書き換えることで調整可能です。

* **アイコンの変更**:
  `icon = "🙋" if role == "user" else "🤖"` の部分を書き換え。
* **検索感度（大文字小文字）**:
  `keyword.lower() in text_line.lower()` の `.lower()` を消すと、大文字小文字を厳密に区別（完全一致に近い挙動）します。
