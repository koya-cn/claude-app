# 要件定義: タスク秘書（起動時のブリーフィング）

Decision:
[0003. 秘書が独自の台帳を持ち、既存のタスク管理サービスを台帳にしない](../../permanent/adr/0003-secretary-owns-its-ledger.md) /
[0008. 起動時のブリーフィングをフックからの文脈注入で行う](../../permanent/adr/0008-briefing-via-session-start-hook.md)

このスライスの受け入れ基準は `BR-` を接頭辞にする。第1スライスの `AC-` とは別の連番。

## 目的

台帳はできたが、中身を見る手段が生のJSONしかない。起動したときに「今やること」が
目に入るようにして、毎朝の棚卸しを成立させる。

## スコープ

### 含む

- 台帳からブリーフィングの材料を取り出すコマンド
- 起動時にそれを文脈へ注入するフック
- 提示の頻度を1日1回に絞る仕組みと、週初回を週次の形にする分岐

### 含まない（後続スライス）

- 収集の自動実行（フックからコネクタを呼べない。ADR 0008）
- タスク管理サービスからの収集
- Claude Code のセッションからの収集
- ボードUI、日次記録の代行生成
- 提示の見た目の固定（整形はモデルに任せる。ADR 0008）

## 前提

- フックの標準出力は利用者の画面ではなく**モデルの文脈に注入される**。人が読む形への
  整形はモデルが行う
- フックはシェルコマンドとして動くため、**コネクタを呼べない**。読めるのは台帳だけ
- 起動の種別（新規・再開・`/clear` 後）を示す値は確認できていないため、**依存しない**

## コマンドとフックの境界

| 層 | 責務 |
|---|---|
| CLI（`claude-secretary brief`） | 台帳から材料を取り出してJSONで出す。整形も頻度制御もしない |
| フック | 頻度を判定し、材料とモデルへの指示を標準出力に書く。失敗しても起動を妨げない |
| モデル | 材料を人が読む形にして最初の応答で提示する |

- CLI `brief`: 台帳を読み、未完了項目・最近片付けた項目・台帳の鮮度をJSONで出す。
  台帳には書き込まない
- フックの状態ファイル: `~/.claude-secretary/last-brief.json`

## 受け入れ基準

### 材料の生成

- BR-1: 未完了の項目を担当（`self` / `group` / `unknown` / `others`）ごとに分けて出す
- BR-2: `done` と `dropped` の項目は未完了の一覧に出さない
- BR-3: 指定した時点より後に完了にした項目を「最近片付けたもの」として出す。
  時点は引数で受け取る
- BR-4: 台帳が空でも失敗せず、空の材料を出す
- BR-5: 台帳の最終収集時刻（`last_seen` の最大）と、そこからの経過日数を出す
- BR-6: 台帳が壊れている場合は検証エラーにする（第1スライスと同じ扱い）
- BR-7: 台帳には書き込まない
- BR-18: 時刻として読めない値やタイムゾーンの無い値があっても落ちない。
  その項目の時刻を無いものとして扱う

### 提示の頻度

- BR-8: 同じ日に2回目以降の起動では提示しない
- BR-9: 日付が変わると再び提示する
- BR-10: 週が変わってからの最初の起動では、週次の形（先週片付けたものを含む）にする
- BR-11: 状態ファイルが無ければ提示する
- BR-12: 状態ファイルが壊れていても提示する。止めない
- BR-13: 提示したら状態ファイルを更新する

### フックの振る舞い

- BR-14: 提示するとき、材料とモデルへの指示を標準出力に書く
- BR-15: 提示しないときは何も書かない
- BR-16: 台帳・設定・状態ファイルのいずれが読めなくても、**終了コードは常に0**にする。
  起動を妨げない
- BR-17: 台帳の最終収集から日が経っていれば、収集を促す指示を含める

## 端と例外

| 状況 | あるべき挙動 |
|---|---|
| 台帳のファイルが無い | まだ収集していない旨と、収集を促す指示を出す |
| 台帳が壊れている | 壊れている旨を出す。黙って終わらない（人が気づけないため） |
| 未完了が0件 | やり残しが無いことを出す。無言にしない |
| 自分が担当の項目が0件 | 他の担当の項目を出す。空の提示にしない |
| 台帳の最終収集が同日 | 収集を促さない |
| 状態ファイルの日付が未来 | 提示する（時計のずれで永久に出なくなることを避ける） |
| 台帳の時刻にタイムゾーンが無い（人が手で書いた） | その項目の時刻を無いものとして扱う。落とさない |
| フックの実行中に例外が起きた | 何も出さず終了コード0で終わる |

## 既存コードへの影響

| 対象 | 影響 |
|---|---|
| `claude-secretary/claude_secretary/cli.py` | `brief` を追加 |
| `claude-secretary/claude_secretary/ledger.py` | 変更しない（読むだけ） |
| `claude-secretary/hooks/` | 新規。フックの実装を置く |
| `claude-secretary/README.md` | `brief` とフックの導入手順を追記 |
| `~/.claude/settings.json` | 利用者が手で登録する（リポジトリ外）。手順を README に書く |
| 第1スライスの収集 | 変更しない |

## 用語

| 語 | 意味 |
|---|---|
| 材料 | ブリーフィングを組み立てるための元データ。整形前のJSON |
| 提示 | モデルが材料を人が読む形にして応答に出すこと |
| 鮮度 | 台帳が最後に収集された時点からの経過 |
